Takumi Anything portable mode

While this file sits next to takumi-anything.exe, Takumi Anything keeps its settings, logs, projects
index and engine store in the TakumiAnythingData folder beside it, and writes nothing to %APPDATA%.
Copy the whole folder to move Takumi Anything with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\takumi-anything) instead.
